# Portfólio Pessoal — wellyngtondev.com.br

Meu site pessoal, desenvolvido do zero em HTML, CSS e JavaScript, sem template,
framework ou biblioteca de terceiros.

🔗 **No ar em [wellyngtondev.com.br](https://wellyngtondev.com.br)**

## Sobre o projeto

A proposta foi construir tudo na mão, inclusive os efeitos visuais, para que o
site funcionasse como demonstração técnica e não apenas como vitrine. Nenhum
efeito usa biblioteca pronta.

## O que tem

- Animação de carregamento no estilo terminal
- Hero com partículas animadas
- Cards de projeto com efeito de inclinação ao passar o mouse
- Layout responsivo, de celular a desktop
- Configuração de SEO: meta tags, `sitemap.xml`, `robots.txt` e estrutura semântica

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Rodando localmente

```bash
git clone https://github.com/Wellyngton-Nascimento-Santos/site-portfolio.git
cd site-portfolio
```

Depois é só abrir o `index.html` no navegador.
